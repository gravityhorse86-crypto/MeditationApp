# 画面一覧

スクショの内容をそのまま書き起こしたもの。【要確認】は末尾にまとめている。
ユーザー（権限）は、非ログインユーザー（未ログイン）かログインユーザー（ログイン済み）の2種類。

## 1. ログイン（`/signin`）｜非ログインユーザー

- 画面パーツ
  - ID（メールアドレス）入力欄
  - パスワード入力欄
  - ログインボタン
  - 登録がお済みでない方はこちら（新規登録ボタンに誘導）
- 機能
  - ID/パスワードでログイン
- データ
  - ID（メールアドレス）
  - パスワード（全角、半角、数字、記号すべて込みで8文字以上64文字未満）

## 2. 新規登録（`/signup`）｜非ログインユーザー

- 画面パーツ
  - ID（メールアドレス）入力欄
  - パスワード入力欄
  - パスワード確認入力欄
  - 新規登録ボタン
  - ログイン画面へのリンク
- 機能
  - ID/パスワードでユーザー登録
  - 登録済みメールアドレスの重複チェック
  - 登録完了後トップページへ遷移
- データ
  - ID（メールアドレス）
  - パスワード（全角、半角、数字、記号すべて込みで8文字以上64文字未満）

## 3. トップページ（`/top`）｜ログインユーザー

- 画面パーツ
  - 「瞑想をはじめる」ボタン
  - 履歴ボタン
  - 設定ボタン
  - ログアウトボタン
- 機能
  - 瞑想前診断画面へ遷移
  - ユーザー情報に応じたおすすめ瞑想を表示
  - 設定画面へ遷移
  - ログアウト
- データ
  - なし

## 4. 設定（`/setting`）｜ログインユーザー

- 画面パーツ
  - BGM ON/OFF
  - トップページに戻るボタン
  - メアドの再設定
  - パスワードの再設定
- 機能
  - BGM ON/OFF変更
  - 設定内容保存
  - トップページに戻る
  - ID（メアド）の変更
  - パスワードの変更
- データ
  - ID（メールアドレス）
  - パスワード（全角、半角、数字、記号すべて込みで8文字以上64文字未満）

## 5. 瞑想前診断（`/analysis`）｜ログインユーザー

- 画面パーツ
  - 現在の気分選択欄
  - 瞑想時間選択欄（3〜30分）
  - ガイド量選択欄
  - 「瞑想を作成する」ボタン
- 機能
  - 現在の気分を入力
  - 瞑想時間を設定
  - ガイド量を設定
  - 入力内容をもとにAIへ瞑想プログラム生成を依頼
  - 生成完了後、瞑想画面へ遷移
- データ
  - 現在の気分
  - 瞑想時間
  - ガイド量
- 追記：気分の選択肢は db-schema.md の `mood` の6種類を使う

## 6. 瞑想（`/meditation`）｜ログインユーザー

- 画面パーツ
  - 残り時間表示（デジタル時計ではなく、たとえば砂時計とか）
  - 背景アニメーション
  - 音声ガイド
  - 一時停止/再開ボタン
  - 終了
  - （設定時間が経ったら）瞑想完了メッセージ
- 機能
  - AIが生成した瞑想プログラムを実行
  - 設定時間に合わせてText to Speechによる音声ガイド再生
  - 残り時間をカウント
  - 一時停止/再開
  - 瞑想終了時に実施結果を一時保存
  - 履歴画面へ自動遷移
- データ
  - 瞑想プログラムID
  - 瞑想開始日時
  - 設定時間
  - 経過時間
  - ガイド文章
  - ガイド再生タイミング

## 7. 履歴（`/history`）｜ログインユーザー

- 画面パーツ
  - 最新の瞑想時間表示
  - 今回の瞑想タイプ表示
  - 過去の瞑想履歴（実施日時、瞑想時間、瞑想タイプ）表示
  - トップページへ戻るボタン
- 機能
  - 瞑想終了後に自動的に履歴画面へ遷移
  - 最新の瞑想内容を表示
  - 過去の瞑想履歴を新しい履歴から順に一覧表示
  - トップページへ遷移
- データ
  - 瞑想プログラムID
  - 瞑想実施日時
  - 瞑想時間
  - 瞑想タイプ

## 【要確認】

1. `/top`：履歴ボタンがあるのに、機能欄に「履歴画面へ遷移」がない
2. `/top`：「おすすめ瞑想を表示」に対応する画面パーツがなく、データも定義がない。1か月で作るなら、外す候補
3. `/meditation`：「実施結果を一時保存」の意味。DBの `meditation_sessions` に保存するのか、一度どこかに置いてから保存するのか
4. `/meditation`：「終了」ボタンで途中終了したとき、`completed = false`、`ended_at` を入れて履歴に残す扱いでいいか
5. `/history`：トップの履歴ボタンから来たとき、「今回の瞑想」の表示をどうするか（直後でないと「今回」がない）
